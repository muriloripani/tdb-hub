O Problema

Atualmente, a Turma do Bem precisa de uma forma mais eficiente de centralizar dados de doadores e parceiros, facilitando o acompanhamento e o relacionamento.

Nossa Solução

Criamos o TdB Hub, uma plataforma tecnológica capaz de gerenciar o histórico de doações, automatizar processos e usar dados para apoiar a tomada de decisão da equipe.

Tecnologias Utilizadas (Sprint 1)

Nesta primeira etapa, o projeto foi desenvolvido focando na estruturação visual utilizando apenas HTML5 e CSS3, garantindo acessibilidade e layout otimizado para computadores (Desktop).
